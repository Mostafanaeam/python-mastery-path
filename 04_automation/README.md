# 04 — Automation

## scripts/

Real scripts for real, repeated daily tasks: file organization, renaming, backups, report generation, etc.

Rule: a script belongs here when it solves a real problem for you more than once.

## experiments/

Quick explorations: try a library, test an idea, benchmark an approach.

Rule: experiments can be messy, but give each one a short note at the top explaining what was tested and what the result was.
