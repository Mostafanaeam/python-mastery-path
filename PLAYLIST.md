# 🎯 Learning Rule

The videos are studied **in order**.

Do not skip ahead just because a later topic looks more interesting.

For every video:

```text
Watch
↓
Understand
↓
Code
↓
Practice
↓
Mark Complete
```

The goal is not to finish the playlist quickly.

The goal is to actually understand what was studied.

---

# 📁 Work System — 01_basics

For the beginning of the journey, keep the process simple.

Inside each topic folder:

```text
topic/
├── README.md
├── examples.py
└── exercises.py
```

### README.md

Only write:

* What I learned
* Important points
* Things I didn't understand
* Small examples if needed

### examples.py

Write the code you learned and experimented with.

Do not copy everything blindly from the video.

### exercises.py

Solve the exercises yourself.

---

# ✅ Daily Workflow

For each video:

### 1. Watch

Watch the video completely.

### 2. Code

Write the examples yourself.

### 3. Experiment

Change the code.

Try different values.

See what happens.

### 4. Exercise

Solve a small problem without looking at the solution.

### 5. Document

Write a few notes in the topic `README.md`.

### 6. Mark Complete

Return to this file and change:

```markdown
- [ ] 001
```

to:

```markdown
- [x] 001
```

---

# 🚫 Don't Do This

* Don't copy the instructor's code line by line.
* Don't spend hours making notes beautiful.
* Don't create unnecessary files.
* Don't try to memorize everything.
* Don't move to the next video if you completely don't understand the current one.

---

# 🧠 Simple Rule

> **Understand → Write → Experiment → Practice → Document → Continue**

That's enough for the beginning.

Do not make the learning system more complicated than the learning itself.
