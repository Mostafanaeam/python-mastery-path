# Debugging Journal

Record every real debugging session, even the quick ones.

Format:

```markdown
## YYYY-MM-DD — Problem

### Symptom

What happened?

### Expected Behavior

What should have happened?

### Investigation

What did I check?

### Root Cause

What was actually wrong?

### Solution

How did I fix it?

### Prevention

How can I avoid this class of bug in the future?
```
