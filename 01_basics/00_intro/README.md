
# مقدمة بايثون

## اي هي بايثون؟

اشعر لغة برمجة و اتعملت سنة 1991  صممها جودو فان روسم

بستخدمها في :-

- تطوير الويب (جزء المستخدم)
- تطوير انظمة التشغيل
- الرياضيات
- انشاء اسكربتات

### اي اللي يقدر يعمله لغة بايثون؟

- تستخدم في انشاء تطبيقات ويل علي الخادم
- تستخدم بجانب البرنامج (النظام) لإنشاء خريطو العمل
- تستخدم لربط البرنامج بقواعد البيانات و تقوم بقراءة و التعديل علي الملفات
- تستخدم لتنظيم البيانات الضخمة و معالجة المعادلات الصعبة في الرياضيات
- تستخدم لإنشاء نموذذج اولي او تطوير برنامج جاهز للإطلاق

## لماذا لغة بايثون؟

- تعمل علي منصات مختلفة (Windows, Mac, Linux, Raspberry Pi, etc).
- طريقة كتابة اللغة سهلة و بسيطة مشابه للغة الانجليزية
- لغة بايثون لها مرونة عالية في كتابة الاكواد لدرجة انه يمكننا كتابة اسطر قليلة لإنشاء برنامج مقارنة بباقي اللغات
- يمكن تشغيل لغة البرمجة علي ال interpreter , يعني لغة بايثون بتسمحلي اكتب الكود واجربها فورا بدون اي تعقيدات مما يعني انشاء النموذج الاولي سريع جدا لإختبار المشروع
- لغة مرنة ومتعددة النماذج، مما يتيح لك كتابة الكود بأكثر من أسلوب برمجي بناءً على ما يناسب مشروعك.

### جبد لتعرفه

- أحدث إصدار رئيسي من لغة بايثون هو الإصدار الثالث، والذي سنستخدمه في هذا المستودع.
- في هذا المستودع، سنكتب كود بايثون باستخدام محرر نصوص. يمكن أيضًا استخدام بيئات التطوير المتكاملة (IDEs) مثل Thonny وPyCharm وNetBeans وEclipse و **vs code**، وهي مفيدة جدًا عند إدارة مجموعات كبيرة من ملفات بايثون.

### مقارنة بنية لغة بايثون بلغات البرمجة الأخرى:-

-  صُممت لتكون سهلة القراءة والكتابة وكأنها نص بشري عادي.
- تستخدم السطر الجديد (الانتقال لسطر جديد عند الضغط على Enter) لإنهاء أو إغلاق الأمر البرمجي، على عكس لغات برمجة أخرى (مثل Java أو C++ أو JavaScript) التي تتطلب وضع رمز الفاصلة المنقوطة (;) أو الأقواس في نهاية كل تعليمة لكي يفهم الكمبيوتر أن السطر انتهى.
-  لغة بايثون تستخدم المسافات البادئة (المسافات الفارغة في بداية السطر) لتحديد بداية ونهاية الكتل البرمجية، بدلاً من استخدام الأقواس المعقوصة {}

# مصطلحات برمجية :-

| الكلمة | المعني |
| :-------- | :------------------------- |
| `workflow` | سلسلة الخطوات والمهام المرتبطة ببعضها بتنظيم دقيق لنقل البيانات أو تنفيذ العمليات من البداية وحتى النهاية |
| `Prototyping` | إنشاء نسخة أولية غير مكتملة أو مبسطة من التطبيق أو البرنامج لاختبار الأفكار وتجربة طريقة عمله قبل بنائه بشكل كامل |
| `production-ready software development` | بناء برمجيات موثوقة وآمنة وقابلة للتوسع لتستخدمها الجمهور الحقيقي في البيئة الحية (Production Environment)، وليس مجرد كود يعمل على جهاز المبرمج أو في بيئة تجريبية. |
| `syntax` | القواعد النحوية أو التركيب اللغوي الذي يحدد كيفية كتابة الأكواد بشكل صحيح يفهمه الحاسوب |
| `Interpreter` | المفسر : برنامج حاسوبي يقرأ الكود البرمجي وينفذه سطراً بسطر بشكل مباشر دون الحاجة لتحويله كاملاً إلى ملف تنفيذي مسبقاً |
| `Compiler` | المترجم : يحول الكود كاملاً دفعة واحدة إلى ملف تنفيذي قبل بدء التشغيل. |
| `Procedural Programming` | البرمجة الإجرائية هي نمط برمجي يعتمد على كتابة الأوامر والتعليمات خطوة بخطوة بترتيب تسلسلي لتنفيذ مهمة معينة. يُعرف هذا النمط أيضاً بالبرمجة الحتمية، حيث يُخبر المبرمج الحاسوب بالأفعال والمهام التي يجب القيام بها بدقة. |
| `Object-Oriented Programming - OOP` | البرمجة كائنية التوجه هي أسلوب برمجي يعتمد على تنظيم الكود في شكل كائنات (Objects) تحاكي الأشياء في الواقع لتسهيل بناء وصيانة البرامج. |
| `Functional Programming` | البرمجة الوظيفية هي نمط برمجي يعتمد على بناء البرامج باستخدام الدوال الرياضية النقية، وتجنب تغيير البيانات أو الحالة العامة. |
| `Indentation` |  تُعنى المسافة البادئة أو الإزاحة في البرمجة هي ترك مسافة فارغة في بداية سطر الكود لتنظيم وترتيب التعليمات البرمجية |
