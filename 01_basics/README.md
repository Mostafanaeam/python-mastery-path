# 01 — Python Basics

One folder per concept topic, in learning order. Each topic folder contains:

- `README.md` — personal notes following the standard topic template below.
- `examples.py` — code written while learning the topic.
- `exercises.py` — exercises attempted.

Folders for topics not yet studied contain only the `README.md` template — do not fill them with copied content; write your own notes as you study.

## Topic Template

Every topic README follows the same structure:

- **Learning Objective** — what should I understand after finishing?
- **Concepts** — the key ideas, in my own words.
- **Examples** — code written while learning.
- **Exercises** — problems I solved.
- **Problems I Faced** — what went wrong?
- **Debugging** — how I diagnosed and fixed problems.
- **Questions** — things I still don't fully understand.
- **Key Takeaways** — what I actually learned.
- **Further Practice** — what to practice next.
