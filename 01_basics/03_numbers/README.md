# الأرقام في بايثون

يوجد ثلاثة أنواع من الأرقام في بايثون:

- int
- float
- complex

للتحقق من نوع أي كائن في بايثون، استخدم الدالة type():
```python
print(type(x))
print(type(y))
print(type(z))
```

## Int
هو عدد صحيح، موجب أو سالب، بدون كسور عشرية، وطوله غير محدود.

```python
x = 1
y = 35656222554887711
z = -3255522

print(type(x))
print(type(y))
print(type(z))
```

## Float

هو عدد، موجب أو سالب، يحتوي على رقم عشري واحد أو أكثر.

```python
x = 1.10
y = 1.0
z = -35.59

print(type(x))
print(type(y))
print(type(z))
```

## Complex

تُكتب الأعداد المركبة باستخدام الحرف "j" كجزء تخيلي

```python
x = 3+5j
y = 5j
z = -5j

print(type(x))
print(type(y))
print(type(z))
```

## Type Conversion

يمكنك التحويل من نوع إلى آخر باستخدام الدوال int() و float() و complex()

====================================

# مصطلحات برمجية :-

| الكلمة | المعني |
| :-------- | :------------------------- |
| `Int or integer` | هو عدد صحيح، موجب أو سالب، بدون كسور عشرية، وطوله غير محدود. |
| `Float` | نوع من بيانات الحاسوب يُستخدم لتمثيل الأعداد التي تحتوي على كسور أو أجزاء عشرية |
| `Complex` | تُكتب الأعداد المركبة باستخدام الحرف "j" كجزء تخيلي |
