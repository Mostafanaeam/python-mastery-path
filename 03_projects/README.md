# 03 — Projects

Projects turn learned concepts into real, working programs.

## mini/

Small, single-file projects — one idea each. Good for practicing a concept cluster (e.g. functions + loops + user input).

## major/

Larger, multi-file projects with modules, tests, and documentation. Start these only when the basics are solid.

## Rules

- Every project gets its own folder with a `README.md` explaining: what it does, why it exists, how it works, and what I learned.
- Add a dependency to `requirements.txt` only when a project actually uses it.
- Run and test each project before considering it done.
- A project is not "finished" because it works — explain how it works in the README.
